# Selected D — asset provenance

Michelle selected Deep Denim Bright Windows (Library `libfile_815b1ecd5c388191873bbbc63aeef446`) and explicitly retained its blue title bar. The local reference was inspected before implementation. These two new assets were generated with the built-in imagegen tool from that reference, then optimized to WebP for this repository. The four existing navigation illustrations were not regenerated or altered.

- `public/homepage/welcome-letter-d.webp`: transparent hero envelope, 1100×1100.
- `public/homepage/denim-wallpaper-d.webp`: repeating denim wallpaper, 900×900.
- Originals remain in the task workspace’s `generated_images` directory.
- Computer windows, text, buttons, navigation, focus, and window controls are HTML/CSS/React, not part of the generated images.
- Typography uses system Times and Georgia. No Soup du Jour webfont was embedded. The reported MyFonts webfont license needs domain/expiry verification before future embedding; no payment or renewal was changed.
