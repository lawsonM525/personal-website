# Explorer icon artwork

Generated with the built-in ImageGen tool on October 26, 2026. Original transparent PNGs are retained in generated_images/. Production exports are 64×64 lossless WebP files in public/explorer/icons/, with transparent margins and nearest-neighbor sampling.

Visual references: [WINDOWS93](https://www.windows93.net/) and [Windows 98 Icon Viewer](https://win98icons.alexmeub.com/). The assets are original generated artwork.
