# Site-wide retro icon artwork

Nine original Windows 98-style transparent icons generated with the built-in image-generation tool. The production exports in `public/interface/icons/` are 64×64 lossless WebP, alpha preserved and nearest-neighbor sampling. Source PNGs remain in `generated_images/`. Existing folder, document, mail and Paint artwork is intentionally reused for the same objects.

Reference: [Windows 98 Icon Viewer](https://win98icons.alexmeub.com/).

All icons are provided through `components/retro-icons.tsx`. Small action symbols are original square-pixel drawings, including arrows, close/minimize, check marks and Paint controls. Lucide is removed from site imports and direct dependencies. New icons should be added here rather than introducing a separate library.
