# Paint playground

## Reference exploration

Explored the live [Windows93](https://www.windows93.net/) desktop, Start menu, PowerNoob, Iconodio stress.exe (Desktop Destroyer), and Minesweeper. PowerNoob exposes many tools and modes; Iconodio pairs a drawing surface with music controls; Desktop Destroyer turns a hammer cursor into immediate cracking and debris. Minesweeper uses a compact beveled board, vivid digital counters, and a changing face. These informed the clear tool modes, sticker drawer, expressive cursor and immediate feedback in Paint.

## Original artwork

32 original ImageGen stickers in two 4×4 transparent atlases. Individual lossless WebP exports live in public/explorer/paint/. Original PNG atlases are retained in generated_images/. Seven existing generated Explorer icons form a Computer sticker pack. All sounds use the existing local synthesizer and shared mute preference.
